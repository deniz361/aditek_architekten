# Asset sources

All images and fonts used by the website are served from this local assets directory.

## ADITEK project photography

The following photographs come from the existing ADITEK reference page:
https://www.aditek.de/referenzen/

- `johanneswerkstrasse.webp`: https://www.aditek.de/site/assets/files/1026/img_johanneswerkstr1.jpg
- `modernisierung.webp`: https://www.aditek.de/site/assets/files/1056/referenz21.jpg
- `effizienzhaus.webp`: https://www.aditek.de/site/assets/files/1092/img_6441.jpg

These are existing ADITEK project photographs, retained for the redesign. The
small source photographs retain their original pixel dimensions. The larger
efficiency-house photograph was reduced to 1400 pixels wide. WebP conversions
strip embedded metadata, including any location information.
